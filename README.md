# Day 9 - Python Data Processing

## Overview

This project demonstrates basic data processing using Python
and Jupyter Notebook.

## Objective

To process structured employee records and generate useful
summary statistics.

## Technologies Used

- Python
- Jupyter Notebook

## Concepts Used

- Lists
- Dictionaries
- Loops
- Conditional statements
- Functions
- Data filtering
- Summary statistics

## Dataset

The project uses sample employee records containing:

- Employee ID
- Employee Name
- Department
- Salary
- Experience

## Processing Performed

The program calculates:

- Total number of employees
- Average salary
- Minimum salary
- Maximum salary
- Average experience
- Department-wise employee count
- Employees earning above average salary
- Department-based filtering

## Interview Questions

### What is data processing?

Data processing is the process of collecting, organizing,
transforming, and analyzing raw data to obtain useful information.

### Why are functions useful in data processing?

Functions make code reusable, organized, easier to maintain,
and reduce code repetition.

### What is structured data?

Structured data is data organized according to a predefined
format, such as rows, columns, or defined fields.
